# ReplyJet 🚀

AI-powered customer reply generator (Arabic + English) built for speed and simplicity.

## ⚡ What is ReplyJet?
ReplyJet helps businesses reply to customers instantly using AI with different tones (professional, friendly, sales).

## 🔥 Features (MVP)
- Generate replies in seconds
- Multiple tones
- Arabic & English support
- Lightweight UI

## 🧠 Tech Stack
- Next.js
- Groq API (Free AI)
- Vercel (Deployment)

## 🚀 Getting Started
```bash
npm install
npm run dev
```

Create `.env.local`:
```
GROQ_API_KEY=your_key_here
```

Turn ReplyJet into a full AI customer support assistant for businesses.
